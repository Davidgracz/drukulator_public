# Drukulator 0.23.21v

- Adds an optional, translucent print-area overlay over apparel photos and fallback mockups.
- Scales the outline to the selected imprint dimensions and labels it with the selected maximum size.
- Synchronizes the overlay with front/back imprint selectors, including print-included items.
- Hides the print-area overlay on profile photos or when no print is selected.
- Does not change price calculations, supplier image mapping, or order logic.
